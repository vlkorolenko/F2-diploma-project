# РОЗДІЛ 3. ПРОГРАМНА РЕАЛІЗАЦІЯ СИСТЕМИ

## 3.1. Структура кодової бази та модулі системи
Програмна система реалізована на платформі Java 21 з використанням фреймворку Spring Boot 3.3.4. Кодова база організована за принципом модульного моноліту з наступною структурою пакетів:
* `ua.edu.chnu.security.audit.engine` — ядро побудови Code Property Graph на основі Spoon AST Model;
* `ua.edu.chnu.security.audit.slicing` — алгоритмічні реалізації Taint Analysis та зворотного/прямого Program Slicing;
* `ua.edu.chnu.security.audit.llm` — клієнтський інтеграційний шар LangChain4j для локального інференсу моделей через Ollama;
* `ua.edu.chnu.security.audit.model` — доменні моделі сутностей вразливостей, вузлів графа та конфігурацій правил;
* `ua.edu.chnu.security.audit.compiler` — пісочниця валідації скомпільованості синтезованих патчів перед генерацією PR.

## 3.2. Налаштування середовища розгортання та інструментальний аудит
Розгортання локального інфраструктурного контуру здійснюється засобами Docker Compose:
* Сервіс PostgreSQL (порт 5432) для збереження аналітичних звітів;
* Сервіс Redis (порт 6379) для координації черг завдань аналізу;
* Контейнер Ollama (порт 11434) з попередньо завантаженою вагою моделі DeepSeek-Coder-6.7B-Instruct.
