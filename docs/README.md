## 2. Зведена матриця нефункціональних вимог (NFRs Matrix)

| Індекс вимоги | Метрика / Параметр | Цільове інженерне значення | Метод інструментальної перевірки |
| :--- | :--- | :--- | :--- |
| **SRS-NFR-PERF-01** | p95 Latency обробки файлу | $\le 35$ секунд на Java-файл до 1000 рядків | Автоматизовані навантажувальні стрес-тести k6 |
| **SRS-NFR-PERF-02** | Пропускна здатність API | $\ge 100$ RPS при піковому пулі з'єднань | k6 Spike Testing |
| **SRS-NFR-SEC-01** | Конфіденційність коду | 0 вихідних мережевих байтів коду (On-Premises) | Аудит мережевого трафіку Wireshark / Trivy |
| **SRS-NFR-ACC-01** | Рівень False Positives | $\le 15\%$ на бенчмарку OWASP Benchmark v1.2 | Еталонний тест-раннер OWASP Scorecard |
| **SRS-NFR-REL-01** | Відмовостійкість черги | 100% збереження завдань через Redis DLQ | Fault Injection Testing / Testcontainers |
| **SRS-NFR-INFRA-01**| Споживання оперативної пам'яті | $\le 4$ GB RAM на контейнер аналізатора | Docker Resource Limits / cgroups monitoring |
