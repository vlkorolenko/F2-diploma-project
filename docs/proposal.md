# Тематична картка кваліфікаційного проєкту (Thesis Proposal)

## 1. Робоча назва проєкту
* **Українською мовою:** Гібридна система статичного аудиту безпеки для Java-проєктів на основі Code Property Graph, Taint Analysis та локальних мовних моделей.
* **Англійською мовою:** Hybrid Static Security Audit System for Java Projects Based on Code Property Graph, Taint Analysis, and Local Large Language Models.

---

## 2. Актуальність та проблематика
Забезпечення безпеки програмного забезпечення на етапі розробки (DevSecOps) є критичною задачею сучасної інженерії ПЗ. Класичні інструменти статичного аналізу коду (SAST), такі як SonarQube чи Checkmarx, спираються на синтаксичні шаблони та правила регулярних виразів. Це призводить до надзвичайно високого рівня хибних спрацьовувань (False Positive Rate сягає 60–75% на реальних репозиторіях), оскільки вони не здатні враховувати бізнес-контекст та складні міжпроцедурні санітизатори. Внаслідок цього розробники витрачають значний часовий ресурс на непродуктивний ручний тріаж попереджень.

З іншого боку, застосування сучасних великих мовних моделей (LLM) безпосередньо до вихідного коду обмежене розміром контекстного вікна (Context Window Exhaustion), високою вартістю обчислень, ризиком галюцинацій та неприпустимістю витоку конфіденційного коду у зовнішні хмарні сервіси (вимоги GDPR та комерційної таємниці).

Виникає гостра інженерна потреба у створенні гібридного підходу: поєднанні строгого компіляторного граф-орієнтованого аналізу, який відсікає надлишковий код, з локальними нейромережевими моделями для точної верифікації та автоматичної генерації безпечних патчів безпосередньо в контурі організації.

---

## 3. Сформована ідея продукту
Система проєктується як хмароорієнтований мікросервісний комплекс статичного аудиту коду з клієнтським веб-інтерфейсом (Single Page Application) та асинхронним обчислювальним ядром. 
Архітектура об'єднує:
1. Компіляторний аналізатор на базі бібліотеки Spoon, що будує Code Property Graph (CPG), інтегруючи абстрактне синтаксичне дерево (AST), граф потоку керування (CFG) та граф потоку даних (DFG).
2. Алгоритмічний модуль Taint Analysis та Program Slicing, що вилучає мінімальний ланцюжок коду (15–30 рядків між джерелом витоку `Source` та точкою виконання `Sink`).
3. Локальну модель глибокого навчання (DeepSeek-Coder / CodeLlama), підключену через LangChain4j, що виконує контекстну верифікацію та синтезує скомпільований Pull Request для усунення вразливості.

---

## 4. Деталізований опис функціоналу (Core Features)
1. **Інтеграція репозиторіїв та завантаження коду:** Забезпечення імпорту вихідного коду через GitHub REST API або завантаження локального ZIP-архіву Java-проєкту.
2. **Побудова Code Property Graph (CPG):** Формування об'єднаного графа (AST + CFG + DFG) для меж класів і методів із повним розв'язанням типів за допомогою Spoon Semantic Model.
3. **Міжпроцедурний Taint Analysis та контекстний слайсинг:** Алгоритмічне трасування руху неперевірених користувацьких даних до критичних функцій (`sinks`) та скорочення розміру коду для аналізу на 95–98%.
4. **Оркестрація локальної LLM через LangChain4j:** Передача нормалізованого кодового зрізу в локальний інференс-сервер Ollama/vLLM для фільтрації хибних тривог та генерації коду виправлення.
5. **Компіляторна валідація патчів (Compiler-in-the-Loop):** Автоматична верифікація згенерованого патчу через `javax.tools.JavaCompiler` та перевірка наявності синтаксичних помилок і регресій.
6. **Інтерактивна візуалізація графа атаки:** Відображення ланцюжка передачі даних (Source-to-Sink) у вигляді графової схеми на фронтенд-дашборді.
7. **Автоматизоване створення Pull Request:** Публікація верифікованого безпечного коду у цільовий GitHub-репозиторій із детальним звітом CWE/OWASP.

## 5. Попередній інструментарій та технологічний стек
* **Мови програмування:** Java 21 (LTS), TypeScript (для клієнтської частини).
* **Компіляторний аналіз та графи:** Spoon 11.1.0, JGraphT 1.5.2.
* **ШІ та інтеграція моделей:** LangChain4j 0.35.0, локальний інференс-рушій Ollama (моделі DeepSeek-Coder-6.7B, CodeLlama-13B).
* **Бекенд-фреймворки:** Spring Boot 3.3.4 (REST API, Security, Scheduling), Spring Data JPA.
* **Бази даних та сховища:** PostgreSQL 16 (метадані, історія аудитів), Redis 7 (черги завдань обробки та кешування графових зрізів).
* **Фронтенд:** React 18, Vite, Cytoscape.js (для рендерингу CPG-графів), Tailwind CSS.
* **DevOps та інфраструктура:** Docker, Docker Compose, Testcontainers, k6 (навантажувальне тестування), GitHub Actions (CI/CD).
