# Тематична картка кваліфікаційного проєкту (Thesis Proposal)

## 1. Робоча назва проєкту
* **Українською мовою:** Гібридна система статичного аудиту безпеки для Java-проєктів на основі Code Property Graph, Taint Analysis та локальних мовних моделей.
* **Англійською мовою:** Hybrid Static Security Audit System for Java Projects Based on Code Property Graph, Taint Analysis, and Local Large Language Models.

## 2. Актуальність та проблематика
Забезпечення безпеки програмного забезпечення на етапі розробки (DevSecOps) є критичною задачею сучасної інженерії ПЗ. Класичні інструменти статичного аналізу коду (SAST), такі як SonarQube чи Checkmarx, спираються на синтаксичні шаблони та правила регулярних виразів. Це призводить до надзвичайно високого рівня хибних спрацьовувань (False Positive Rate сягає 60–75%), перевантажуючи команди розробників неінформативними попередженнями.

## 3. Сформована ідея продукту
Система проєктується як хмароорієнтований мікросервісний комплекс статичного аудиту коду з клієнтським веб-інтерфейсом (Single Page Application) та асинхронним обчислювальним ядром на базі бібліотеки Spoon та локальної мовної моделі.

## 4. Деталізований опис функціоналу (Core Features)
1. Інтеграція репозиторіїв та завантаження коду через GitHub API або ZIP.
2. Побудова графа CPG на основі синтаксичного розбору.
3. Міжпроцедурний Taint Analysis.
4. Локальний ШІ-аналіз через LangChain4j.
5. Автоматизоване створення Pull Request.

## 5. Попередній інструментарій та технологічний стек
* Мови: Java 21, TypeScript
* Фреймворки: Spring Boot 3, React
* Аналіз: Spoon, JGraphT
* ШІ: LangChain4j, Ollama
* Бази даних: PostgreSQL, Redis
* DevOps: Docker
