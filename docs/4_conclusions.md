# ВИСНОВКИ

У кваліфікаційній роботі вирішено актуальну інженерну задачу розробки гібридної системи статичного аудиту безпеки для Java-проєктів. На основі проведених досліджень та експериментів зроблено такі основні висновки:
1. Проведено аналіз сучасних підходів до виявлення вразливостей у коді та доведено неефективність виключно синтаксичних сканерів (через рівень False Positives понад 60%) або ізольованого застосування мовних моделей (через ліміти контекстного вікна та галюцинації).
2. Спроєктовано та формалізовано специфікацію вимог за стандартом ISO/IEC/IEEE 29148:2018 із вимірюваними чисельними показниками продуктивності та надійності.
3. Розроблено багаторівневу архітектуру системи за методологією C4 Model (Context, Container, Component) з чітким розмежуванням обов'язків та протоколів обміну.
4. Науково обґрунтовано вибір бібліотек Spoon та JGraphT для побудови Code Property Graph і вилучення кодових зрізів (ADR-001).
5. Реалізовано асинхронний конвеєр оркестрації локальної LLM через LangChain4j, що гарантує повне збереження конфіденційності вихідного коду (On-Premises комплаєнс).
6. Експериментальні дослідження на тестовому наборі OWASP Benchmark v1.2 підтвердили суттєве зниження рівня хибних спрацьовувань при забезпеченні автоматизованого формування безпечних Pull Request.
