# ВСТУП

## 1.1. Актуальність теми дослідження
Стрімкий розвиток концепцій неперервної інтеграції та розгортання (CI/CD) і методології DevSecOps висуває принципово нові вимоги до швидкості та якості аналізу вихідного коду програмних систем. Сучасне корпоративне програмне забезпечення на мові Java є основою критичної інфраструктури, фінансових екосистем та розподілених хмарних сервісів. Проте індустріальна практика свідчить, що традиційні засоби статичного аналізу коду (Static Application Security Testing — SAST), такі як SonarQube, Fortify або Checkmarx, генерують критично високу частку хибних спрацьовувань (False Positive Rate, що за даними досліджень NIST та OWASP сягає від 60% до 80%). Класичні сканери аналізують синтаксичні шаблони без глибокого розуміння семантичного контексту, міжпроцедурних санітизаторів та бізнес-правил, перевантажуючи команди розробників неінформативними попередженнями.

З іншого боку, пряме використання генеративних великих мовних моделей (LLM) для аудиту цілих кодових баз стикається з фундаментальними обмеженнями: скінченним контекстним вікном (Context Window Exhaustion), високою обчислювальною вартістю, ризиком стохастичних галюцинацій та неприпустимістю витоку інтелектуальної власності у зовнішні хмарні сервіси через регуляторні вимоги (GDPR, HIPAA, банківська таємниця). 

Актуальність даного кваліфікаційного дослідження зумовлена необхідністю подолання вказаного технологічного розриву шляхом розробки гібридної системи, яка поєднує суворий детермінований компіляторний аналіз на основі графа властивостей коду (Code Property Graph — CPG) та спрямованого аналізу потоків зараження (Taint Analysis) із локальними мовними моделями через відкритий фреймворк LangChain4j. Такий підхід дає змогу вилучати компактні, але вичерпні за контекстом зрізи вразливого коду (15–30 рядків замість тисяч) та автоматично генерувати верифіковані компілятором виправлення (Pull Request), що істотно підвищує продуктивність інженерних команд.

## 1.2. Науковий апарат дослідження
* **Об'єкт дослідження:** процес автоматизованого виявлення та усунення вразливостей вихідного коду програмного забезпечення на мові Java.
* **Предмет дослідження:** методи побудови графа властивостей коду (CPG), алгоритми міжпроцедурного Taint-аналізу для формування контекстних кодових зрізів (Program Slicing) та локальні нейромережеві моделі синтезу безпечних патчів.
* **Мета роботи:** Проєктування та розробка гібридної системи автоматизованого статичного аудиту безпеки та виправлення коду Java-проєктів для мінімізації рівня хибних спрацьовувань та автоматичної генерації верифікованих компілятором Pull Request.

### Завдання дослідження:
1. Проаналізувати сучасні підходи та існуючі програмні засоби статичного аудиту безпеки коду Java, виявивши їхні інженерні обмеження та фактори високого рівня False Positives.
2. Обґрунтувати вибір технологічного стеку та архітектурних патернів для синтаксичного розбору вихідного коду, побудови графових структур даних та інференсу локальних мовних моделей.
3. Спроєктувати дворівневу сервісну архітектуру системи за методологією C4 Model (Context, Container, Component) із суворою ізоляцією обчислювального ядра аналізу.
4. Розробити алгоритмічне забезпечення для побудови Code Property Graph (об'єднання AST, CFG та DFG) та вилучення релевантних кодових зрізів за алгоритмом Taint Analysis.
5. Реалізувати інтеграційний конвеєр на базі фреймворку LangChain4j для оркестрації локальної мовної моделі без виходу за межі корпоративного периметра.
6. Спроєктувати підсистему компіляторної валідації синтезованих патчів (Compiler-in-the-Loop) та автоматизованого формування Pull Request у цільовий репозиторій.
7. Провести експериментальне дослідження ефективності розробленої системи на еталонному наборі тестів OWASP Benchmark v1.2 для кількісної оцінки точності детекції та зменшення рівня хибних спрацьовувань.
