Кваліфікаційний проєкт бакалавра, спеціальність F2 Інженерія програмного забезпечення.

**Тема:** Метод та програмні засоби автоматизованого виявлення вразливостей вихідного коду на основі графів властивостей коду та великих мовних моделей.

**Topic (EN):** Method and Software Tools for Automated Source Code Vulnerability Detection Based on Code Property Graphs and Large Language Models.
